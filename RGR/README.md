# 📘 Keyboard Trainer (Клавиатурный тренажёр)

Консольное приложение для тренировки скорости и точности печати текста.  
Проект выполнен в рамках расчётно-графической работы (РГР), вариант 16.

---

## 📌 Описание

Программа предназначена для развития навыков слепой печати.  
Пользователь вводит текст, а система оценивает:

- точность ввода
- количество ошибок
- затраченное время

Результаты сохраняются в журнал.

---

## ⚙️ Возможности

- Тренировка ввода:
  - слова
  - предложения
  - режим «Змейка»
  - тренировка клавиш
- Подсчёт статистики:
  - правильные символы
  - ошибки
  - время выполнения
- Сохранение результатов в файл
- Простое консольное меню
- Логирование событий
- Конфигурация через `config.txt`

---

## 🚀 Сборка проекта

```bash
mkdir build
cd build
cmake ..
make
```

## ▶️ Запуск программы
```bash
    ./RGR
```

## 🧪 Запуск тестов
```bash
    ./tests
```
## ⚙️ Конфигурация
Файл config.txt:
```bash
    WORDS_COUNT=7
    SENTENCES_COUNT=2
    TIME_LIMIT=30
```
## 📊 Файлы программы
1. log.txt — логирование работы программы
2. leaderboard.txt — сохранённая статистика пользователей

## 📄 Отчёт
Отчёт расположен в папке report/:
1. RGR.tex — исходник отчёта
2. RGR.pdf — готовый документ
3. photo/ — скриншоты работы программы
