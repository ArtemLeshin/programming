# 🏧 ATM 2077 — NeuralBank Cyberpunk Terminal

## 📌 Что сделано

Реализована полноценная симуляция работы банкомата на C++ с киберпанк-атмосферой.

### Функционал
- ✅ Ввод PIN-кода (3 попытки → блокировка карты)
- ✅ Проверка баланса
- ✅ Снятие наличных с комиссией **1% (минимум 30 руб)**
- ✅ Пополнение счёта
- ✅ История последних 5 операций
- ✅ Журнал транзакций в бинарный файл (append-only)
- ✅ Восстановление баланса после краша из журнала
- ✅ Лимиты: **10 000 руб за раз** | **50 000 руб в сутки**

## 🚀 Как собрать и запустить

### 1. Сборка через CMake

```bash
mkdir build && cd build
cmake ..
make
```
#### Запуск (обычный)
```bash
./bin/atm2077
```

#### Запуск с душой 🔥
```bash
./launch.sh
```

### Очистка данных
```bash
make clean_data
```
## 🎮 Как пользоваться

1. **Ввод данных**: Введите номер карты (например, `4200-1234-5678-9012`).
2. **PIN-код**: Используйте `1234`.
3. **Меню действий**:
    * `1` — Проверить баланс
    * `2` — Снять наличные
    * `3` — Пополнить баланс
    * `4` — История операций
    * `5` — Выход

## ⚙️ Технические детали

* **Язык**: C++11
* **Сборка**: CMake 3.10+
* **Хранение данных**: бинарные файлы (`journal.bin`, `cards/`, `accounts/`)
* **Комиссия**: 1% от суммы, но не менее 30 рублей
